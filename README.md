# myTunes

A responsive, single-page entertainment landing page for music, movies, TV shows, and gift cards. Built with plain HTML and CSS, with no build tools or package installation required.

## Preview

Open [`index.html`](./index.html) in a browser, or publish the repository with GitHub Pages:

1. Push the project files to a GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch you uploaded and the **/(root)** folder, then save.

GitHub Pages will provide a link to the published site after deployment completes.

## Features

- Responsive layout for desktop, tablet, and mobile.
- Sticky navigation with links to the page sections.
- Music, entertainment, and gift card sections.
- Keyboard focus styles and reduced-motion support.
- Roboto page typography and a Montserrat myTunes wordmark.

## Run locally

No build step is needed. Open `index.html` directly in your browser. Alternatively, serve the project folder with any local static web server.
